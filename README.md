# ТрансЛайн

Демо-панель логистики: автопарк, рейсы, водители, клиенты, карта и экспорт данных.

## Запуск

Откройте `index.html` или запустите локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Карта OpenStreetMap и библиотека Leaflet загружаются из интернета.

## GPS и данные

Кнопка GPS один раз запрашивает координаты устройства через браузер и сохраняет их для выбранной машины в `localStorage`. Нужны разрешение пользователя и защищённое соединение (HTTPS или localhost). Чтобы видеть реальное движение грузовика постоянно, потребуются установленный в машине GPS-трекер и серверный API: эта демо-версия к ним не подключена. Позиции без GPS-фиксации примерные.

Рейсы, водители, клиенты и GPS-фиксации сохраняются только в текущем браузере и не синхронизируются между устройствами.
