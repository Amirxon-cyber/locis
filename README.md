# ТрансЛайн

Логистический портал с панелью управления перевозками: автопарк, рейсы, водители, клиенты, карта и экспорт данных. Главная страница объединяет быстрые переходы по разделам и сводку по работе.

## Запуск

Откройте `index.html` или запустите локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Интерактивная карта на данных OpenStreetMap загружает дорожные тайлы с `tile.openstreetmap.de` через Leaflet. Интернет нужен для загрузки карты и библиотеки.

## GPS и данные

Кнопка GPS один раз запрашивает координаты устройства через браузер и сохраняет их для выбранной машины в `localStorage`. Нужны разрешение пользователя и защищённое соединение (HTTPS или localhost). Если браузер отказал в доступе, разрешите «Местоположение» в настройках сайта рядом с адресной строкой или введите широту и долготу в карточке машины. Координаты устройства — это местоположение телефона/компьютера, на котором нажали кнопку, а не автоматическое местоположение грузовика.

Чтобы видеть реальное движение грузовика постоянно, потребуются установленный в машине GPS-трекер и серверный API: эта демо-версия к ним не подключена. Позиции без GPS-фиксации примерные.

Рейсы, водители, клиенты и GPS-фиксации сохраняются только в текущем браузере и не синхронизируются между устройствами.

## Внешний вид

Светлую или тёмную тему можно переключить в верхней панели или в разделе «Настройки» → «Внешний вид». Выбор хранится отдельно от рабочих данных в текущем браузере.
